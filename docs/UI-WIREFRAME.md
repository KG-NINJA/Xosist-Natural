## 操作フロー

1. 質問を入力 → 「クエリ生成」
2. 各クエリの「最新で開く」「話題で開く」で公式検索を開く
3. 必要な投稿をコピーして「3.」のエリアに貼り付け
4. 「自然な文章にまとめる」でレポートを生成
5. 必要ならコピーして他のツールに渡す

## 将来拡張ポイント

- 日付プリセット（24h / 7d / 30d）
- スタイル選択（レポート / 会話 / 箇条書き）
- 投稿のKeep/Discard簡易フィルタ
- エージェント用プロンプトの直接コピー
- ブラウザ拡張との連携（投稿一括抽出）
